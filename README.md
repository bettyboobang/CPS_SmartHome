# CPS Smart Home 3D - Симулятор кіберфізичної системи
Інтерактивний 3D-веб-симулятор кіберфізичної системи "Розумний будинок" з навігацією від першої особи, реалізований за допомогою бібліотеки **Three.js** та **Node.js REST API бекенду**. 
Проєкт демонструє роботу автоматизованого сценарію керування освітленням на основі детекції наближення користувача до датчика руху.

## Клієнтська частина
* index.html - базова HTML-розмітка. 
Підключає необхідні бібліотеки Three.js, lil-gui, Stats.js через CDN, розмитий екран інструкції з підключенням бекенду та завантажує ES6-модуль js/main.js.

* style.css - кастомні стилі для інтерфейсу.
Забезпечує стилізацію напівпрозорого вікна інструкцій (glassmorphism), індикатора стану бекенду, оверлея огляду та прицілу (crosshair).

* SmartDevice.js - містить об'єктно-орієнтовану ієрархію класів, яка відповідає за логіку та стан усіх розумних пристроїв у кіберфізичній системі.
Фундаментом модуля є базовий клас SmartDevice, який зберігає унікальний ідентифікатор пристрою, його зрозумілу назву та булевий прапорець поточного стану.
Він надає універсальні методи для перемикання стану та зчитування його актуального значення.
Від базового класу успадковуються два спеціалізовані модулі.
Клас SmartLight відповідає за смарт-лампу, пов'язуючи логічний стан із параметрами Three.js — він керує яскравістю точкового джерела світла та змінює матеріал 3D-моделі з темно-сірого на яскраво-жовтий при ввімкненні, а також дозволяє плавно регулювати інтенсивність освітлення.
Клас MotionSensor реалізує логіку датчика руху, зберігаючи координати пристрою у 3D-просторі та радіус детекції.
Він містить метод обчислення відстані до камери користувача, який при підході на критичну відстань фіксує поду в системі та візуально перемикає колір 3D-моделі датчика із зеленого режиму очікування на червоний колір тривоги.
